# Monthsary Gift System (PHP + MongoDB + Bootstrap)

Romantic, minimal monthsary gift system with lockable gifts and a monthly gallery.

See composer.json for dependencies. Run a local server with:

```bash
php -S localhost:8000 -t public
```

Defaults:
- MongoDB URI: mongodb://127.0.0.1:27017
- DB: monthsary
- Initial user: admin@example.com / love-you-forever
